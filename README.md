## File-processing APIs and WooCommerce integrations

I maintain six focused APIs with runnable examples and fictional samples:

| Your workflow | Start here |
| --- | --- |
| Export supported Access MDB/ACCDB tables to CSV or typed JSON | [Access File Extractor](https://rapidapi.com/IsraelDiego/api/access-file-extractor) |
| Optimize PNG/JPEG assets inside an HTML5 advertising ZIP | [CreativePack](https://rapidapi.com/IsraelDiego/api/creativepack) |
| Add a visible buyer watermark while retaining supported PDF size layers | [PatternCopy PDF](https://rapidapi.com/IsraelDiego/api/patterncopy-pdf) |
| Preview supported ONIX book updates before applying them in WooCommerce | [ShelfRelay ONIX](https://rapidapi.com/IsraelDiego/api/shelfrelay-onix) |
| Recalculate supported XLSX formula caches and inspect preservation findings | [CalcReceipt](https://rapidapi.com/IsraelDiego/api/calcreceipt) |
| Check an explicit PDF/A profile and compare before/after failing rules | [ArchiveProof](https://rapidapi.com/IsraelDiego/api/archiveproof) |

[Examples, synthetic samples and both WooCommerce connectors](https://github.com/israeldi/flamingo-api-examples) · [CreativePack GitHub Action](https://github.com/marketplace/actions/creativepack-html5-zip-optimizer) · [Local MCP tools](https://github.com/israeldi/flamingo-file-tools-mcp)

A free [Agensi workflow skill](https://www.agensi.io/skills/flamingo-file-tools-access-pdf-zip-onix) provides instructions and self-contained temporary Python clients for Access exports, CreativePack ZIP optimization, PatternCopy inspection/stamping and ShelfRelay previews. The direct route runs in a supported file-capable agent workspace without a separate Flamingo MCP server, pip install or client download. See the [full agent setup guide](https://github.com/israeldi/flamingo-api-examples#use-the-apis-from-your-agent) for prerequisites and key configuration. The local MCP bridge remains an optional alternative for compatible clients. Processing requires your own RapidAPI app key and a separate subscription for each selected API; usage is separately metered.
